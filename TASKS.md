# Kickoff checklist

- [ ] Confirm repository owner, public provider namespace, and license.
- [ ] File `docs/upstream-proposal.md` with Bugsink.
- [ ] Wait for and record upstream lifecycle and token decisions.
- [ ] Initialize Go module and scaffold from `terraform-provider-scaffolding-framework`.
- [ ] Add disposable Bugsink Docker Compose test environment.
- [ ] Implement and test team/project CRUD only after delete support exists.
- [ ] Add import, generated docs, GoReleaser, signed release workflow, and Registry publication.
